### Featured projects

**[clicky4Windows](https://github.com/Donferarri92/clicky4Windows)** · C# · .NET 8 · WPF

A lightweight Windows desktop AI companion that lives in the system tray. Hold **Ctrl+Alt** to talk — it captures your screen, transcribes your voice **locally** with Whisper.net, sends both to **Claude via AWS Bedrock**, speaks the answer back through Windows TTS, and flies a cursor dot to the relevant on-screen element with a bezier-arc animation. DPI-aware, multi-monitor, and ships as a single self-contained `.exe` — no server, no cloud STT.

**[qa-guradian](https://github.com/Donferarri92/qa-guradian)** · React · FastAPI · MongoDB

A website quality-assurance tool. A React + Radix/shadcn front-end sits over a **FastAPI** back-end that crawls sites (BeautifulSoup / aiohttp), runs quality checks, handles auth with **JWT + bcrypt**, and generates downloadable **PDF reports** (ReportLab).
